# 📊 NumPy and Pandas Basics for Future Data Scientists
**University of Michigan | Coursera**

This repository contains my solutions and technical assessments for the **"NumPy and Pandas Basics for Future Data Scientists"** course, provided by the **University of Michigan** on Coursera.

## 🗂️ Repository Contents
The assessments demonstrate practical skills in numerical computing and data manipulation:
- `module_1_assessment.ipynb`: Basic Array Operations and NumPy fundamentals.
- `module_2_assessment.ipynb`: Data Manipulation and Cleaning with Pandas.
- `module_3_assessment.ipynb`: Advanced Pandas Features and Data Grouping.
- `module_4_assessment.ipynb`: Final Challenges, Data Concatenation, and DataFrame merging.

## 🛠️ Technologies & Libraries Used
- **Python 3**
- **NumPy**
- **Pandas**
- **Jupyter Notebook**
